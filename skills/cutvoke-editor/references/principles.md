# Shared creative principles

Read for a new edit or substantial redesign. For a local correction, use only the affected principle and the current command schema. This is layer 1; choose a relevant workflow next, then adapt the project-plan reference to the actual assignment.

## Preserve the brief

Infer audience, viewing surface, intended feeling or takeaway, source constraints and expressive intensity from the request and existing project. Ask only when a consequential choice remains unresolved. A request for stronger artistic expression authorizes creative editing within its scope; it does not authorize new model installation, paid generation, media uploads or publication. Existing authorization remains valid.

Select workflow by **purpose and work type**, with genre as a secondary influence. A restrained interview, forceful abstract MV and factual travel diary need different decisions. Neither gentle cuts nor spectacle is a universal default. Respect approved direction during local revisions.

## Turn an intention into an observable change

Give each important passage a viewer-facing purpose and source evidence. Record asset IDs and source intervals, the action/emotion/information that makes a selection useful, sound value and uncertainties. Include reactions, pauses and apparently imperfect takes when they carry meaning. A transcript, similarity rank or attractive still is a candidate selection, not proof that a passage works.

For an expressive treatment, describe **what appears, changes and resolves**, its relation to a subject/action/music cue, and how it develops across shots. An effect name, parameter count or poetic title does not establish that expression. The source's existing visual impact must not be reported as a new editing achievement.

Discover live effects/presets and read exact command/effect schemas before translating the idea into operations. Separate verified available operations, a proposed technique requiring discovery, and unavailable operations. Try a supported alternative or explain a material limitation. Keep the user's meaning and requested intensity when adapting.

## Test the uncertain part cheaply

For a substantial creative change, choose a short passage that includes its main reveal, motion or handoff. Compare the same source range and intended duration with a simple baseline and a purposeful variant; change a specific design variable where useful. Use a normal-speed moving preview with sound when the host supports it. Check whether the result produces the intended difference, then refine or replace the approach before repeating it throughout the film. A fixed number of variants or duration is not required.

Static frames help inspect composition and edges. They cannot establish timing, pacing or sound. Preparing a preview is not watching it. If the model/host cannot receive images or play audio, still perform authorized mechanical edits and provide review artifacts; identify the unverified sensory judgments and request targeted human review when necessary. Never pretend to have seen or heard an output.

## Keep decisions reviewable

Use reversible clip/effect operations, source timecodes, exact revisions and normal undo points. Preserve original media and the editable project. For a local edit, inspect that interval and its affected neighbors; for a complete delivery, review the full exported work where playback is available and state any remaining gap. A command, decode check or effect count cannot certify artistic quality.

Evaluate applicable dimensions: understandable progression, picture/sound relationship, composition/readability, continuity, factual/message coherence and pacing. Describe a concrete time, observed issue, change and recheck rather than inventing a universal taste score. See [review.md](review.md).

Research basis: [editor needs and control](https://arxiv.org/abs/2109.07809), [editing-quality dimensions in a limited cinematic-ad study](https://arxiv.org/abs/2608.24329). These inform this workflow; they do not establish automatic aesthetic evaluation or performance guarantees.
