# A plan for this project

Layer 3. Use for a new edit or substantial creative redesign after shared principles and the relevant workflow. Adapt the depth to uncertainty and impact. A subtitle correction needs the target entity, intended change and affected review range, not a new film treatment or mandatory user approval.

Keep the plan under the bound `projectRoot`, normally `notes/edit-plan.json` or a short existing project note. Reuse an adequate existing plan. This planning note is **not a command payload or a machine-enforced schema**.

Include only useful decisions:

- Brief: audience/surface, intended takeaway or feeling, expressive intensity, permitted sources, deliverables and assumptions inferred from the request.
- Selected guidance: the shared principles and relevant workflow IDs, plus any deliberate variation; genre labels alone do not determine editing style.
- Selects: source ID/path, source in/out, visible action or information, useful sound, narrative role and uncertainty.
- Passages: timeline range, viewer-facing change, picture/action, music/voice/ambience cue, recurring motif and its development.
- Treatments: intended entry/change/exit, foreground/background order and supported commands/effect IDs **after** runtime discovery. Mark unverified operations as proposals and document a suitable fallback.
- Prototype/review: representative range, simple baseline, proposed variant, actual artifact/revision, observed difference, keep/change decision and unresolved sensory checks.
- Delivery: target settings, editable handoff, local review scope, final export evidence and remaining limitations.

## Example of a visual event

For a brief seeking a forceful architectural MV, a proposed passage might read:

> At the water's circular motion, the circle opens onto a doorway in the next shot; a moving foreground edge briefly hides the join. The musical entrance coincides with the new space becoming readable. Later the circular motif expands from a local detail into the scene's main composition.

Then identify matching source intervals and actual available mask/motion/compositing operations. If the source shapes or available tools cannot support the design, choose another visible connection; do not label an ordinary dissolve as an accomplished transformation. Test the specific passage in motion before scaling the idea across the film. A bright overlay alone is not evidence that this event happened.

## Revision loop

Record observed problems and improvements with time ranges, not only adjectives. Keep useful alternatives reversible and retain the current revision. Recheck the changed range and its dependent neighbors, including audio. When a prototype fails the brief, change the design rather than repeating the same parameters across more clips. Continue within existing authorization; ask only for a material unresolved choice or missing resource.
