# Audio-first editing, offline

[简体中文](README.zh-CN.md)

Build a six-second editable sound-led sequence with two original tone sources, a flat-color card and three captions. This is a reproducible teaching example, not a finished music track or speech-recognition demo. It uses only local loopback HTTP/MCP, no external network service, model download or personal library.

## Run

Use a source checkout with the [development dependencies](../../CONTRIBUTING.md#development-setup), FFmpeg/ffprobe and a built Web editor. From the repository root, in the activated Python environment:

```sh
python examples/audio-first/demo.py --output .artifacts/audio-first-01
cutvoke serve --data .artifacts/audio-first-01/data
```

Choose a **new directory every time**. The script refuses an existing directory, including a partially completed run, so keep failed evidence and use another name. Open the URL printed by `serve`, then the **Audio first · editable tutorial** project. Keep its whole directory, not only the database. MP4/package paths are relative to the run directory in `result.json`.

## What the script does

1. Creates an isolated project **before** importing media with `projectId`. This keeps the library and timeline in the same project.
2. Generates a quiet two-tone bed and a short high cue using Python. Labels them explicitly as `music` and `sound_effect` through the supported project-scoped asset API. Role labels organize media; they do not change the mix or infer meaning from filenames.
3. Fetches each source's real waveform PNG and audition stream. The saved stream must match the source bytes. Source waveforms do not include timeline gain, fades or other tracks.
4. Uses `command_preview` and one revision-checked `edit.batch` under a short editing lease. The music gain is 0.6 with 0.8-second endpoint fades; the cue at 2–3 seconds has gain 0.4 and its own short fades. Three captions remain editable. The lease is released before handoff.
5. Captures actual preview frames and a two-second composed mix excerpt around the cue using `preview_audio`. `mix-audition.wav` includes the timeline mix, unlike the source audition.
6. Exports through `export.enqueue`, checks streams/duration, fully decodes the MP4 and measures audio. It requires non-silent unclipped audio and endpoint RMS below 30% of a steady middle interval. It also verifies that the 880 Hz cue is present only in its intended interval. These are numerical checks, not a claim of subjective listening quality.
7. Packages the editable project, unpacks it into a **different** directory, verifies the timeline (ignoring relocated source paths), exports again and compares decoded PCM exactly.

## Human editor checks

The script does not simulate these checks or mark them passed. Use moderate playback volume before listening.

- Find the music and sound-effect assets; inspect their role filters and waveforms, and audition each source.
- Open the timeline, play across the cue at 2 seconds, and confirm audible fades at the beginning/end. Inspect both the mixed audio and the actual picture, not just the advancing time display.
- Select the caption “A small cue”, change its wording and save. Confirm it remains on the same interval and the preview updates. Undo once and verify restoration.
- Inspect the audio clip volume/fade controls. Change the music gain, preview and undo; the original generated source file must remain unchanged.
- To inspect the restored package independently, stop the first server and run:

```sh
cutvoke serve --data .artifacts/audio-first-01/roundtrip/projects.sqlite
```

Open the restored project and check captions, two audio clips and playback. The legacy restored library's source audio-role catalog may not be preserved by the package format; the editable timeline and its gain/fades are checked. Do not describe this as a full library backup.

## Files and privacy

`result.json` records objective evidence; `calls.json` records the local MCP tool sequence. `frames/` contains three actual pictures and two source waveforms. `mix-audition.wav` is an excerpt, not the full export. `roundtrip/` is a separately restored editable project. All generated media/databases/logs stay in ignored `.artifacts/` and must not be committed.

The tones and solid-color card are original, generated by this MIT-licensed repository script. No third-party media, recordings, voice, downloaded fonts or external service is used. Installed CutVoke may use its bundled fonts when rendering captions. Do not replace these fixtures with private footage in public evidence.
