# CutVoke editing examples

Each example includes English and Simplified Chinese videos, distinctly named
portable projects, original media, animated previews and verification records.

| Example | English guide | 中文说明 |
| --- | --- | --- |
| Motorcycle film / 摩托短片 | [CHASE THE LIGHT](chase-the-light/README.md) | [逐光而行](chase-the-light/README.zh-CN.md) |
| Handheld travel vlog / 手持旅拍 | [Coastal Joy](travel-vlog/README.md) | [海岸快乐日记](travel-vlog/README.zh-CN.md) |

Run `git lfs pull --include="examples/showcases/**"` to retrieve the large files.
Use **Unpack and open / 解包打开** in the latest CutVoke source build for the
`.cutvokepack` projects. Both languages share the same source media.
