## 渲染修复

真实帧对比发现，透明轨同轨有多个相邻片段时，FFmpeg `concat` 会丢掉后续 Alpha 片段的效果。轨道合成改为把各片段按时间戳叠到共享透明画布；叠加前按片段声明时长裁切，避免上一段末帧延伸到下一段。含显式转场的轨道继续走转场合成路径。

人物特效预览源现在跨前后片段连续取样，防止样片在切点重置动作。补充回归验证：特效只影响后段、前段保持不变、后段画面与单独放置时一致。
