# 快速应用、时间线筛选与动画属性

## 快速应用

在编辑器中按 **Ctrl/⌘+Enter**，或点击工具栏的搜索图标。
输入名称或关键词，使用上下键选择，Enter 应用，Esc 关闭。
`e:` 只找效果，`p:` 只找内置预设，`m:` 只找常用命令。
完整名称排在关键词命中之前；不使用宽泛的字母子序列匹配。

效果应用到当前片段，使用和资源库拖放相同的编辑命令，支持撤销。
无选择、不适合的素材类型及轨道锁定会给出禁用原因。更复杂的素材与转场条件仍由编辑服务校验。
输入文字、打开其它对话框或 Agent 持有编辑租约时，不接管全局编辑快捷键。
效果与预设独立加载，预设检查较慢时仍可搜索和应用已加载的效果。

## 时间线筛选

时间线搜索可查找片段 ID、素材名和效果名称；多个词同时满足才显示。
下拉框可只显示已选片段，或只显示有关键帧的片段。
筛选条件在编辑期间保留，切换工程后恢复为空。

筛选只改变显示，不改变轨道显隐、音轨、预览画面或导出。
已选择但被过滤隐藏的片段会有数量提示。Ctrl/⌘+A 只选择当前筛选可见的片段；输入框里的 Ctrl/⌘+A 仍选择文字。
需要确认整个工程时，点击清除筛选。

## 动画曲线

选中片段后，在右侧属性中的关键帧区域选择参数。
数值曲线可拖动节点改变时间和值；变化速度曲线显示相同标量通道的变化率，当前用于观察，不提供速度手柄编辑。
上一/下一关键帧会定位工程播放头，同时填写该节点的局部时间和值。

选中多个节点后，可以一次设置：

- 缓入缓出：在编辑区按 F9，或点击按钮。
- 线性：各段按恒定数值变化率插值。
- 保持（阶梯）：直到下一关键帧的精确时间才跳到新值。

批量操作保留节点 ID、时间和值，并作为一次撤销记录。保持插值在前端预览、片段裁剪和渲染中采用相同边界规则。
这里的缓入缓出修改所选节点所引出的插值段。二维空间贝塞尔、独立时间缓动和按弧长分配时间的节点位于单独的“空间运动路径”区域，见 [合成与路径控制](COMPOSITING_WORKFLOW.md)。

外部 Agent 可调用 `clip.keyframe`，例如以下 payload：

```json
{
  "clipId": "shot-1",
  "param": "opacity",
  "action": "interpolate",
  "keyframeIds": ["node-1", "node-2"],
  "interpolation": "cubic-bezier",
  "bezier": [0.333333, 0, 0.666667, 1]
}
```

一次最多 1000 个不同节点，必须都属于指定参数通道；非法输入不会部分提交。
命令仍需使用当前工程版本、命令 ID 与编辑租约。先通过 `editor_help` 查询参数规范。

## 效果与复杂参数

右侧效果条可搜索当前片段上的效果，或只显示相对于默认值已变化的项。
参数变化、旁路、效果时间区间以及该实例的参数动画都算作已修改。
每个重复效果独立显示，更新、重排、旁路、删除和实时草稿按实例操作。
点击“编辑参数”会定位对应实例，不跳到同类首个效果。

展开效果属性，可直接编辑支持的几何与关键点结构，包括光源跟踪点、方向关键点、遮挡轮廓、反射区域以及亮度转场的区域和阈值曲线。
可选结构通过启用开关增删，点列表支持增删与数值编辑。范围和点顺序不合法时保留本地输入，并提示修正；有效参数才提交。

“重置参数”恢复静态默认值，保留关键帧和效果时间区间。
需要移除参数动画时，应在关键帧编辑器中删除相应节点。

Agent 的局部修改仍采用默认合并模式。需要移除可选结构或恢复默认值时，显式使用完整替换模式：

```json
{"clipId":"shot-1","instanceId":"effect-instance-id","params":{},"replaceParams":true}
```

省略 `replaceParams` 时保持既有局部合并行为。完整替换仍经过统一效果 schema 校验，可保存、撤销并通过 MCP/HTTP 使用。

## 已修改属性总览

选中一个片段后按 U 查看动画属性，600 毫秒内再按一次 U 查看全部已修改属性，也可在属性区点击切换。
总览覆盖静态参数、动画通道、旁路、区间、效果混合、轨道遮罩、参数绑定、空间路径和实例覆盖。
点击一项进入对应编辑区；动画通道会同步选中。视图切换不写入工程，也不接管输入框或对话框中的按键。
这里比较的是默认值与当前片段的权威数据，不是文件历史的差异，也不表示支持全工程范围的 AE UU 面板。
