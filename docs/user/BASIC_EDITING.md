# 基础剪辑与素材恢复

## 时间线选择、复制与批量操作

- 单击选择片段；Ctrl/Command 单击增减选择，Shift 单击连续选择；在时间线空白处拖动框选。Ctrl/Command+A 选择片段。
- 拖动已选片段可以整体移动，保持彼此时间和轨道关系。绑定图层随所属视频移动、删除；锁定轨道或视频片段位置冲突会拒绝整次操作。
- Ctrl/Command+C 复制独立片段快照，Ctrl/Command+V 在播放头插入；Ctrl/Command+D 在选中区间末尾插入副本；Ctrl/Command+X 剪切。菜单与时间线底部也提供复制和粘贴入口。
- 插入粘贴会顺延后续轨道内容、字幕、标记和相关自动化。跨越插入点的片段按原时间映射拆开。复制的绑定关系和复合片段使用新标识，可以一次撤销。
- 多选后，右侧显示批量编辑面板，可整体移动、删除，或统一设置音量、淡入和淡出。留空的属性保持各片段原值。

## 精确裁剪

选中片段，在右侧“精确裁剪”输入时间线起点、终点、时长或源入出点，点击“应用裁剪”或按 Enter。Escape 取消尚未应用的输入。

支持秒（`1.5`）、帧数（`45f`）和非丢帧时码（`00:00:01:15`）；提交按工程帧率对齐。修改起点与拖动左边缘相同，会裁掉前段并调整源区间；整体平移请使用拖动或批量移动。源入出点按播放方向显示，倒放时入点较大、出点较小。曲线变速可在既有范围内裁剪，定格使用固定源帧。

视频片段显示当前可见范围的缩略帧，音频片段显示源音频波形；裁剪、变速、倒放和重新链接后会更新。条带按需加载并缓存，不参与成片渲染。

## 大文件与取消导入

导入与重新链接使用独立的媒体体积限额，JSON 命令仍有较小的请求体限制。媒体默认单文件限额为 16 GiB，可通过环境变量 `CUTVOKE_MAX_MEDIA_BYTES` 调整。上传采用流式临时文件，不把整份大文件装入服务内存。

导入区域显示当前文件、已传字节及文件队列进度。“取消当前及后续上传”停止当前网络传输和剩余队列。已经成功的素材保留；中断的临时文件不会登记为素材。异常终止服务后，下次启动会回收已死亡上传进程留下的片段。

## 文件夹批量重新链接

在素材面板选择“从文件夹批量重新链接”，选择素材目录并扫描。先预览候选，再确认恢复；同名候选有歧义时必须明确选择。

新导入素材记录原始内容指纹与相对目录信息，恢复时核对内容指纹。旧素材缺少指纹时默认不选中，需逐项预览并人工确认；服务器仍核对文件大小、类型、时长和画面规格。恢复保持登记路径与时间线引用，不改动剪辑位置。

## 保存与历史

修改自动事务保存，状态栏显示保存状态。撤销和重做历史均持久化，可跨服务重启恢复。撤销后提交新编辑会清除旧分支的重做历史。工程状态同步会检查服务端版本；未变化时仅返回轻量状态，外部 Agent 的编辑仍能刷新到界面。
