# 口播与访谈示例提示词

[English](prompts-talking-head.md) · [连接 Agent](agent-skill.zh-CN.md) · [访谈剪辑原则](../../skills/cutvoke-editor/references/workflows/explainer.md)

每次复制一条给已连接的 Codex、Claude Code 或 Cursor，把方括号替换成自己的本地工程、文件和目标。这些是剪辑需求，不是 CutVoke 直接理解的自然语言指令；Agent 需要查询当前版本的工具并执行。

## 开始前

- MCP 与人工编辑器使用**同一个数据目录**。先查询 `editor_help({})`、`runtime`；规划访谈剪辑时读取 `editor_help({"topic":"creative","guide":"explainer"})`。
- 明确工程和素材。用 `project_list` / `project_summary` 确认工程，用 `project_query` 获取字幕正文与精确时间。生成文件放在工程已记录的目录内，除非明确指定另一交付位置。
- 陌生命令先通过 `editor_help`（`topic: command`）获取参数结构，再看 `commands_list` 的 `previewSupported`。`command_preview` 只试算结构，不渲染视频，也不是每条命令都支持。
- 成组修改使用 `edit_lock`、当前 `expectedRevision` 和稳定的 `commandId`，人工接手前释放租约。发生版本冲突时刷新并核对，不强行执行旧方案。
- 只使用有权编辑的素材。安装可选模型或把素材发送到其它服务前必须征得同意。本页不需要云端视频生成。

## 十条可复制的需求

### 1. 先检查，不剪辑

> 检查[源文件]，准备做访谈剪辑。告诉我时长、分辨率和是否有音轨，展示几张代表画面。暂时不要剪。

**Agent：** `media_import` → `media_inspect` → 针对素材的 `preview_frames`；导入不会自动创建时间线片段。**检查：** 文件是否正确、旋转方向、音轨和构图。静帧不能证明人声清晰，还要听源音频。

### 2. 缩短长停顿，保留呼吸

> 在[工程]中缩短超过 0.8 秒的停顿，每个剪口两侧各保留约 0.15 秒，短停顿不动。先展示计划删除的区间。保留原意，并正常速度复核每个改动边界。

**Agent：** 用 `caption.autoSegment` 的 `minSilence: 0.8`、`applyToProject: false` 获取源时间候选，再预演和提交确认过的 `sequence.deleteRange`，从后向前删。**检查：** 呼吸、辅音、刻意停顿和音画同步。

`minSilence` 是静音检测的时长下限，不是“保留呼吸”参数。检测器返回占位区间而非真实转写，不会直接删除视频；当前检测阈值固定为 −30 dBFS。删除前必须把源时间映射到目标片段的时间线；裁切、移动、重复使用、倒放或变速片段需要明确换算，或单独渲染分析副本。剪过以后不要继续使用旧时间码。`audio.splitSentences` 只写出独立音频文件，不会联动剪视频。序列删区间会影响全轨、字幕和标记，先核对范围。

### 3. 按句子或词删除音画

> 从[工程]的转写中删除“[完整原句]”及对应音视频。先展示字幕 ID、区间和前后文。如果有多处同样的话，先问我要哪一处。

**Agent：** 找到已校对并写入工程的字幕，再预演/提交带 `captionIds` 的 `transcript.delete`；逐词删除使用一个 `captionId` 与 `wordIndices`，且必须有有效逐词时间。**检查：** 出现位置、语义、剪口和所有受影响轨道。此操作会删除媒体时间，不等于删字幕或改错字。摘要不是转写，不要编造逐词时间。

### 4. 本地转写，审核后入轨

> 为[片段]生成[语言]的本地字幕草稿，使用已安装的适合的语音模型。如果需要装依赖或下载模型，先告诉我。让我校对后再加入时间线。

**Agent：** 检查本地能力；`caption.transcribe` 返回提案，校对后用 `caption.bulkAdd` 与返回的来源绑定提交。**检查：** 人名、术语、口音、多人重叠和时间。来源或片段时间变化后重新识别。安装与离线使用见[本地 ASR](LOCAL_ASR.md)。`caption.autoSegment` 不能代替转写。

### 5. 只修字幕，不剪声音

> 把[时间]处字幕的“[错误写法]”改成“[正确写法]”。声音、视频和字幕时间不变，给我看修正后的画面。

**Agent：** 找到准确字幕，预演/提交 `caption.update`，再用 `preview_frames` 检查对应时刻。**检查：** 拼写、换行、媒体时间不变。这是文字修正，不用 `transcript.delete`；文字变化时不要凭空补逐词时间。

### 6. 保留横版，另做竖版

> 保留原横版，另做一条 9:16 版本，讲话者居中。导出前看开头、中间、结尾。如果会裁掉另一位讲话者或重要手势，先展示取舍。

**Agent：** 用 `sequence.duplicate` 指定如 1080×1920 与 `reframe: cover`，检查画面，必要时调整支持的变换和关键帧。**检查：** 头顶空间、人脸、手势、字幕、原横版是否保留。`cover` 是几何居中裁切，不是人脸检测或自动讲话者追踪。双人画面可考虑 `contain` 或专门布局，不要声称自动保全两人。

### 7. 查看最大剪口前后四帧

> 导出前给我看四帧：两处最大删除区间的剪口前后各一帧，标明当前时间线时间。之后带声音动态复核这些边界。

**Agent：** 把已确认的修改映射到当前时间，用 `preview_frames` 指定四个有效时刻与 `expectedRevision`；连续预览可用 `preview_prepare` / `preview_job`。**检查：** 跳切、黑帧、字幕和同步。四张静帧不能证明人声节奏或音频正确。单次最多六帧，时刻必须早于序列结束。

### 8. 安全导出，不覆盖

> 把已审核的活动序列导出为[新文件名].mp4，放在当前工程的 exports 目录。保留源文件和所有已有文件，告诉我最终路径、分辨率和时长。如文件名已存在，先问我换什么名字。

**Agent：** 运行 `project.preflight`，再通过 `command_apply` 提交 `export.enqueue`，指定绝对 `outPath` 和 `overwrite: false`，合理间隔查询 `export_job` 到终态。**检查：** 只有 `succeeded` 才算成功；核对实际路径、分辨率、整段解码、首尾画面及音频。排队不等于导出完成。独立工程要求引擎输出位于自己的 `exports/` 或 `backups/` 内，选择绝对路径前先用 `project_directory` 确认。通过该引擎接口不能直接导出到工程外的源文件旁。应说明约束，不重试被拒绝的路径、不移动源文件、不绕过限制。如需要另存交付副本，先明确获授权的位置及可用的文件交付方式。不授权上传发布。

### 9. 只撤销最后一步

> 撤销[工程]最后一次修改，告诉我恢复了什么，展示受影响区间。不要重置工程或删除导出文件。

**Agent：** 核对 `project_events` 和当前状态，确认最后一步确实是目标后再提交 `history.undo`。**检查：** 源偏移、字幕、时长是否恢复。如果已有别人后续修改，先询问，不撤销别人的工作。撤销不等于清理磁盘或取消导出。

### 10. 交还可编辑工程

> 停止编辑，把[工程]交还给我。释放编辑锁，概述剪切和待确认字幕，在工程目录保存一份新的可编辑工程包，不覆盖已有文件。

**Agent：** 查询 `project_summary` / `project_events`，释放 `edit_lock`，再以当前 `expectedRevision`、工程 `exports/` 内的明确 `outPath` 和 `overwrite: false` 调用 `project_package`。**检查：** 编辑器可写、活动序列正确、工程包存在、源素材可用。打包不代表授权分享，未经要求不发送。

## 实测内容与边界

Codex 选择并通过真实 CutVoke stdio MCP 子进程执行了第 **1、2、3、5、6、7、8、9** 条背后的工具操作，可用下面的验证程序复现。这验证工具路径，不代表自然语言提示词在不同 Agent 或其配置界面中的成功率。第 3 条测试的是人工编写合成参考文字的逐词删除，不是语音识别；第 1 条代表帧在第 7 条阶段检查。此程序未执行第 4 条 ASR 或第 10 条打包交接。

记录的实跑环境为 Linux、Python 3.12.14、FFmpeg 7.1.5，使用 CutVoke 0.3.5 源码 `e45af6d` 加本次文档/验证程序改动。

素材是十秒 640×360 原创色卡视频，中央标记配合成音调，含两个 1.5 秒静音与一个 0.2 秒短停顿。没有私人素材、真实姓名、私人路径、模型下载或外部服务。

- 检测出两个长静音，按已审核区间删除、两侧各留 0.15 秒后，时间线为 7.6 秒；解码输出音频仍保留短停顿。
- 删除一个人工标注词，音画缩短 0.5 秒；撤销精确恢复序列、源偏移和逐词字幕。仅改字幕文字不改变媒体轨道。
- 创建独立 360×640 `cover` 版本，保留原 640×360 序列；四张真实剪口附近 PNG 中央标记完整。
- 7.6 秒竖版输出带音频并通过整段解码；第二次导出到同名位置被拒绝，源文件与已有输出哈希不变。

在具备 CutVoke 运行依赖及 FFmpeg/ffprobe 的源码目录运行：

```bash
python tools/verify/verify_talking_head_prompts.py --output .artifacts/talking-head-check
python tools/verify/check_asset_layout.py
```

每次指定**新目录**。程序在其中保存隔离的可编辑工程库、合成源文件、预览 PNG、MP4、`calls.json`、`mcp.log` 和 `result.json`。请查看 PNG 并播放成片再判断画面和听感。合成时序/像素检查通过，**不代表**自然人声准确率、呼吸自然度、语义保真、人脸追踪、所有客户端兼容性或艺术效果通过。
