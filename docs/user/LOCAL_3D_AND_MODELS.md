# 本机三维、可选抠像模型与外部 AI 交接

三维渲染不需要 AI 模型。神经网络抠像使用可选的本地模型；人工操作不需要连接大模型。外部 AI 帮助选目标或验收时，才要求该 AI 和它的客户端实际支持图片输入。

## 本机三维场景

工具栏点击“添加三维场景”，选择新图层后展开属性中的“本机三维场景”。可以添加立方体、球体和平面，导入 OBJ 网格，设置材质图片，调整摄像机、灯光和各物体的动画姿态。

接口使用 `composition.scene3d` 新建独立图层；`effect.update` 按精确 `instanceId` 修改；`scene3d.import` 将 OBJ 文本导入该效果实例。先调用 `editor_help(topic="command", command="composition.scene3d")`、`editor_help(topic="command", command="scene3d.import")`，以及 `effects_list` 查询实际 schema。编辑遵守版本、租约和撤销协议。

- 摄像机采用透视投影，支持目标点、视野角度、近远裁剪面和姿态关键帧。物体支持位置、旋转、缩放、颜色、透明度、粗糙度和图片材质；灯光为一个点光源与环境光。
- 同一个场景内按照逐像素深度处理网格遮挡，与物体列表顺序无关。透明材质使用深度剥离，默认 4 层，可设为 1–8 层。超过层数的透明表面不会全部参与合成。
- 优先使用本机 OpenGL 3.3；缺少可用驱动时自动回退到软件光栅化。源码运行可安装 `uv pip install 'cutvoke[graphics]'`；桌面构建锁定并收集 ModernGL/glcontext。`local_model_status` 会返回实际渲染器和设备；编码器使用 NVENC 不代表三维渲染也使用 NVIDIA GPU。
- 单场景最多 32 个物体、16384 个三角面。OBJ 最多 2 MiB，展开后最多 4096 顶点、8192 三角面；支持面三角化、负索引和 UV。网格数据嵌入工程，可随工程移动。MTL 和外部引用不自动加载，导入会返回提示；材质图片通过工程素材上传管理。
- 材质图片会参与预检、工程包收集及解包后的路径重写。含三维材质的工程包需要更新后的 CutVoke 打开，旧版会明确提示包格式不支持。按 `objectId` 替换网格时保留该物体的材质、位置和动画。
- 图片材质最多 3200 万像素，渲染时缩至不超过 2048×2048。姿态关键帧最多 32 个，时间单位为片段局部秒，严格递增。

这是可编辑的本机三维合成场景。目前不包含物理光线追踪、投影阴影、景深、骨骼动画或摄像机解算。普通轨道仍按图层顺序合成；不会自动从普通视频推断真实场景深度。视频中的前景遮挡可结合人工蒙版、轨道遮罩或抠像透明片段完成。软件回退与复杂透明场景的预览不保证实时。

## 可选本地神经网络抠像

“效果条 → 人物抠像”保留直接运行的人工入口，支持看图选点、排除点、多帧修正、进度、取消、应用和撤销。SAM2 可跟踪选中的普通物体，并不局限于人物。模型、运行环境和视频处理都在本机；不会因为连接 MCP 自动下载权重。

首次使用时，在“设置 → 可选抠像组件”或效果条中的抠像入口，点击“启用”，检查设备、下载量和空间，然后“同意并安装”。“人物抠像”适合移除人物背景；“物体跟踪抠像”适合跟踪点选的人物或物体。普通剪辑无需安装这些组件，首次启动也不会自动下载。

高级选项可更换保存磁盘、优先大陆或海外来源、选择离线 ZIP。安装失败或取消后，已下载内容保留，点击“继续安装”复用；同一版本与保存位置无需重复确认。界面和 MCP 共用进度，关闭设置页不影响后台安装。安装完成会实际运行模型检查，但画面效果和速度仍建议用短片试用确认。

`local_model_status` 返回就绪状态、模型用途、安装工具入口和数量限制：MediaPipe 用于全体人物，MagicTouch 用于单帧提示选择，SAM2 用于有点提示和修正帧的视频物体跟踪。运行环境由软件独立管理，不需要自行安装 Python、Git 或输入命令。生成物保存在当前工程的媒体目录，原素材保留，应用结果是一次可撤销的源替换。

### AI 必须自行判断是否可用

MCP 初始化说明、工具描述、`editor_help(topic="local-models")` 和状态接口都包含以下约束。无需另装 Skill：

1. AI 先判断**当前模型能否理解图片，以及当前客户端能否把工具返回的图片传给模型**。不能仅凭模型名称或工具存在就认定支持。
2. 不支持或不确定时，停止 AI 抠像选取与视觉验收，告知用户使用手工入口。不要把能力字段填为 `true` 来绕过限制。
3. 支持时，先通过 `preview_frames` 查看真实源画面，再提交实际看到的选点。`videoInput` 不是必需条件，可逐张检查 PNG。
4. 启动与应用工具要求 `agentCapabilities={"selfAssessed":true,"imageInput":true,"toolImageInput":true}`。这是调用方的自我声明，软件不能替 AI 证明它确实看到了图片。

| 工具 | 用法 |
| --- | --- |
| `local_model_status` | 检查可选模型与本机三维渲染器，无下载、无上传。 |
| `extension_status` / `extension_plan` | 无工程也能查询安装状态，检测设备与空间并形成安装计划；不下载。 |
| `extension_confirm` / `extension_install` | 记录用户实际同意/拒绝，携带确认凭据异步安装。普通剪辑指令不视为安装同意。 |
| `extension_job` | 查询或取消同一个界面/MCP 安装任务；重试原计划复用已确认范围和缓存。 |
| `extension_export_offline` | 将完整校验的下载缓存打包供离线安装，不包含用户素材。 |
| `local_matting_start` | 传当前工程版本、`clipId`、能力声明及提示，返回 `jobId`。SAM2 默认采用 selected 模式。 |
| `local_matting_job` | 查询/取消人工或 AI 创建的同一任务；状态查询不要求视觉能力。 |
| `local_matting_apply` | 实际看过源图与结果后，传当前版本、有效编辑租约和稳定命令 ID 应用；重试同一命令幂等。 |

SAM2 每次最多 16 个提示帧，每帧最多 8 个点；同时最多 2 个待处理任务。`atSeconds` 是**源素材绝对秒数**，必须处于所选片段的源区间内；`x/y` 按源图宽高归一化到 0–1，`label=1` 选中，`label=0` 排除。当前模型作业处理源视频并输出透明 ProRes MOV，处理时间和磁盘用量取决于源视频长度。导出成功不等于发丝、快速遮挡等细节已经合格。

## 界面如何让外部 AI 接手

人工直接点击抠像无需外部 AI。需要选取帮助或结果验收时，在“外部 AI 协助”中明确发起请求。

- 请求按工程、片段和版本写入本机持久队列。界面显示等待、处理中、完成、拒绝、取消和版本失效；可以复制交接说明。
- 支持视觉的 AI 主动执行 `agent_session(operation="register", capabilities=...)`，然后在用户授权的工作期间执行 `agent_requests(operation="wait", waitSeconds=25, ...)`。这个已在执行的工具调用会在界面创建请求后返回。AI 再 `claim`、读取实际画面、执行授权范围内的工作，并 `complete` 或 `decline`。
- 会话和认领有效期均为 120 秒，长任务通过 `agent_session(operation="heartbeat", ...)` 续期。完成时必须返回当前 `result.reviewedRevision`；认领旧版本请求会标记失效。认领和报告本身不修改时间线，也不代替编辑租约。
- **没有活跃等待调用时，不会凭空唤醒空闲 AI。** MCP 连接存在、登记过能力，都不等于 AI 正在等待。此时请求保留，用户可以把复制的说明交给自己的 AI。软件不会启动聊天客户端、猜测用户当前会话或向其他聊天发送消息。

要实现“点击后连空闲 AI 也自动启动”，还需要对应 AI 客户端提供并授权会话唤醒/回调集成。不能用所有 MCP 客户端都具备这种能力的假设替代实际适配。该边界也通过 `automaticWake=false` 对外公开。

## 支持范围与下载来源

目前一键安装验收覆盖 Windows x64：人物、SAM2 CPU、SAM2 CUDA 12.8。其他系统暂不提供未验收的安装包，界面会明确说明。设备检查会区分基本适用、CPU 可能较慢、内存不足和无支持包；没有短片实测时不承诺处理速度。

下载自动在固定可信来源之间选择，校验大小和 SHA-256；切换线路不会更换模型或计算后端。大陆源包括 NJU、华为、ModelScope 和项目 GitCode，海外源包括 Python、PyPI、PyTorch、Google 和 Meta。实际来源、测试网络范围及离线包契约见[安装与下载说明](../development/optional-extension-installation.md)。
