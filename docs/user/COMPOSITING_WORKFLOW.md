# 合成、模板与动画控制

这些控制使用工程里的稳定片段、效果实例和序列 ID。人工编辑器与外部 Agent 共用保存、预演和撤销协议。

## 调整层与效果混合

工具栏的“添加调整层”创建一条独立调整轨。它只影响已经合成的下方画面，作用时间是调整片段的区间；上方画面随后叠加。
调整层支持调色、画面效果、效果区间和整体不透明度。用每个效果的局部范围限制空间作用区域。
调整层的位移、旋转、缩放和片段入场动画会被明确拒绝，避免按钮成功但渲染无变化。

“效果条 → 效果混合”提供不透明度、正常/正片叠底/滤色/相加/差值，以及可羽化的归一化矩形范围。
混合使用预乘 Alpha 的插值，适用于会改变透明度的蒙版效果。调色效果也可作为可混合的精确实例参与效果顺序。
变换、标题和转场仍使用各自的专门控制。

```json
{"type":"composition.adjustment","payload":{"clipId":"grade","timelineStart":2,"timelineEnd":6}}
{"type":"effect.composite","payload":{"clipId":"shot","instanceId":"fx_123","compositing":{"opacity":0.6,"blendMode":"screen","region":{"x":0.1,"y":0.2,"width":0.5,"height":0.6,"feather":0.08}}}}
```

## 可选择轨道遮罩

“属性 → 图层合成”选择任意同层级视频、图片、文字或预合成片段作为遮罩源。
可使用 Alpha 或亮度，可反相；同一源可供多个片段引用。
勾选“仅用作遮罩”保留源的计算而不把它当普通画面覆盖。隐藏源图层也不会丢失其被引用的画面。
源片段不在当前时间时覆盖率为零，反相后为一；不会把源片段的末帧无限延续到别的时间。

```json
{"type":"clip.composite","payload":{"clipId":"letters","compositing":{"matteOnly":true}}}
{"type":"clip.composite","payload":{"clipId":"shot","compositing":{"matte":{"clipId":"letters","channel":"alpha","invert":false}}}}
```

引用必须在同一个序列或嵌套合成中。循环引用、删除仍被使用的源、未知 ID 会在提交前拒绝。
工程打包和独立目录移动保留这些引用；重新定位的是素材路径，而不是重新分配片段 ID。

## 共享预合成与实例参数

“当前工程 → 预合成与依赖”可以把其他制作序列作为共享实例插入当前时间线。
修改母版会更新它的实例；“模板参数与预合成”中的实例覆盖只改变选中实例。
“恢复母版参数”删除覆盖值，不修改母版本身。

在母版中选中片段，选择要公开的属性并命名，可公开位置、缩放、旋转、不透明度、音量或文字内容。
Agent 也可公开现有可动画效果参数，例如 `effect:<instanceId>:sigma`。
一个合成最多公开 128 项控制。共享依赖最多 16 层、2,048 个实例；循环在保存前拒绝。

```json
{"type":"composition.expose","payload":{"sequenceId":"title-master","controls":[{"id":"heading","label":"标题","clipId":"title","param":"content"}]}}
{"type":"composition.instance","payload":{"sequenceId":"title-master","clipId":"version-a","timelineStart":0,"timelineEnd":4}}
{"type":"composition.override","payload":{"clipId":"version-a","values":{"heading":"第一版"}}}
```

公开控制的目标使用稳定 ID。已有实例仍覆盖某个控制时，不能直接删除或改成不兼容的控制；先恢复这些实例的母版参数，再修改控制声明。
显式覆盖一个参数会替代该参数的母版关键帧、绑定和空间路径通道；其他动画保留。覆盖 X 不会移除母版 Y 的路径。
复制序列或成组复制片段时，蒙版源、绑定源、公开参数目标和效果实例路径一起重映射；公开控制名称保留。

“进入预合成”打开独立编辑窗口，显示当前合成的局部时间、轨道、片段和真实渲染帧。
双击子合成可继续进入，面包屑可返回。内层修改通过 `composition.edit` 提交，仍是主工程的一次原子撤销。
这是母版编辑窗口，实例覆盖在外层属性中编辑。

```json
{"type":"composition.edit","payload":{"path":["outer","inner"],"command":{"type":"effect.add","payload":{"clipId":"picture","effectId":"cutvoke.fx.blur","params":{"sigma":5}}}}}
```

## 参数绑定与空间路径

“参数绑定”支持另一片段的可动画标量属性，或时间、固定值、正弦控制器。
线性倍率、偏移和局部时间偏移均有界，输出会限制到目标参数允许的范围。
绑定不运行任意脚本，不允许循环；解除绑定后恢复原有静态值和关键帧。
当前绑定目标为画面属性及已有可动画效果参数，不包括音频音量。

```json
{"type":"clip.bind","payload":{"clipId":"shot","param":"rotation","binding":{"source":{"type":"sine","amplitude":8,"frequency":0.5},"offset":0}}}
```

“空间运动路径”把二维空间曲线与时间缓动分开：每个点可编辑入/出空间手柄，区段可编辑独立时间贝塞尔。
中间节点可按路径弧长分配时间，首尾点保持固定时间。支持 2–32 点。
路径与源入点一起保留裁剪时钟，移动整个片段不改变其内部路径；固定速度变化使用原始速度基准。
曲线变速和冻结片段暂不接受空间路径；先移除路径再应用这类时间映射。移除路径后恢复原有 X/Y 通道。

```json
{"type":"clip.motionPath","payload":{"clipId":"shot","points":[{"at":0,"x":0,"y":0,"outX":120,"outY":-100},{"x":180,"y":0,"roving":true},{"at":3,"x":400,"y":0,"inX":-120,"inY":-100}]}}
```

## 基础效果算子

资源库提供以下可组合基础效果：

| 效果 | 可编辑能力 |
| --- | --- |
| 分形噪声 `cutvoke.fx.fractalNoise` | 固定种子、空间尺度、八度、随时间演化、对比度、原画混合 |
| 湍流置换 `cutvoke.fx.turbulentDisplace` | 两个确定性噪声场驱动横向/纵向位移，保留 Alpha |
| 波浪扭曲 `cutvoke.fx.waveWarp` | 横/纵方向、像素振幅、波长、频率与相位 |
| 矢量路径 `cutvoke.fx.vectorPath` | 二维点、贝塞尔切线、描边/填充、路径修剪、修剪时间点、重复器及重复变换 |
| 三维平面与摄像机 `cutvoke.fx.cameraPlane` | 三轴旋转、平面深度、摄像机平移/距离、焦距及姿态时间点 |
| 光流路径蒙版 `cutvoke.fx.trackedMask` | 逐时刻轮廓点、置信度、羽化和反相；支持人工修正 |

参数是可保存、可撤销的结构化数据，几何参数可在效果表单中编辑；不把缓存视频写进工程权威数据。
噪声、置换、波浪、矢量和摄像机参数可加入不含用户素材、文件路径或字幕内容的安全效果配方。
跟踪轮廓来自用户画面，不能作为安全公共配方导出。

## 三维平面与摄像机

在效果库搜索“三维平面与摄像机”。角度使用度；位置和距离使用平面高度单位，焦距使用虚拟毫米（垂直片门 25 mm）。
默认距离 2、焦距 50 时保持原有画幅。`poseFrames` 最多 32 个严格递增时间点，按角度和位置数值插值，每帧重新计算透视。
姿态时间是片段局部秒数，窗口预览保留原来的时间。效果表单可编辑和增删姿态点。

```json
{"type":"effect.add","payload":{"clipId":"shot","effectId":"cutvoke.fx.cameraPlane","params":{"poseFrames":[{"at":0,"rotationY":-25,"cameraDistance":2},{"at":3,"rotationY":25,"cameraDistance":2.6}]}}}
```

X/Y 旋转限制为 ±85°；平面越过 0.05 的近裁切面时整体隐藏，以避免奇异投影。
各平面仍按时间线轨道叠放，不提供网格模型、空间相交遮挡、三维灯光、景深或摄像机解算。
实现采用 [FFmpeg perspective 滤镜](https://ffmpeg.org/ffmpeg-filters.html#perspective) 执行实际透视投影。

需要网格、灯光和逐像素深度遮挡时，使用独立的“添加三维场景”，而不是 `cameraPlane` 平面效果。它支持本机 OpenGL/软件渲染与 OBJ；可选神经网络抠像也有独立入口，见[本机三维、模型与 AI 交接](LOCAL_3D_AND_MODELS.md)。

## 光流辅助轮廓蒙版

先添加钢笔蒙版并绘制轮廓，再在属性区展开“蒙版光流跟踪”。分析完成后确认结果并点击“应用跟踪结果”。
分析不修改工程；应用时在原位置替换该蒙版实例，保留实例 ID、旁路、效果区间、混合参数和后续效果顺序，一次撤销即可恢复。
已有较新的工程修改时，旧分析结果不能再应用。

单次最多分析 30 秒源画面、256 个采样；输入最多 128 个控制点，曲线由与静态蒙版相同的实现采样，再限制为 64 个跟踪顶点。
使用前后向光流一致性判断失败；失去纹理、越界、轮廓剧变或置信度不足时停止，并返回失效时刻。
分析以源画面坐标运行，先移除前置几何形变、蒙版动画、冻结或变速。支持线性、平滑和贝塞尔初始轮廓。

```json
{"type":"media.trackMask","payload":{"sourcePath":"D:/media/shot.mp4","start":0,"seconds":5,"sampleFps":8,"pathMode":"linear","points":[{"x":0.2,"y":0.2},{"x":0.8,"y":0.2},{"x":0.5,"y":0.8}]}}
```

返回的 `pathFrames` 可由 Agent 编辑，也可在效果参数表单中选择采样帧、展开 points，逐点修正。较长列表分页显示，避免一次生成数万个输入框。
这属于可编辑的光流辅助轮廓，不是神经网络 Roto Brush，也不保证处理头发、快速遮挡或重新出现的物体。

## 工作区和预览预算

拖动左右面板边界可调整宽度，也支持边界上的方向键。
工具栏“工作区”可保存最多 8 个命名布局，恢复面板宽度、显隐与时间线高度，并提供布局重置。
布局保存在本机界面设置里，不影响视频或工程协作内容。

“设置 → 空闲预览预算”控制预热开关、连续预览、提前秒数、空闲延迟、单次墙钟预算和当前工程的预热范围。
连续准备或预热用完预算就停止；播放和定位继续按需取当前窗口。
离开工程、改变画面或终止预热会取消旧请求，取消令牌只影响对应后台请求。

## 性能分析

“当前工程 → 合成性能分析”从播放头采样 0.1–5 秒，按所选尺寸连续运行两次。
它记录实际 FFmpeg 滤镜区间、程序图层生成工作线程时间和缓存命中；工程数据和撤销历史不变。

首次运行可能已经命中磁盘缓存，不能直接称作“冷缓存”。滤镜区间包括调度等待且可能重叠，不能相加伪装成总耗时或独占 CPU 时间。
解码、变换、合成与编码仍包含在墙钟时间中；性能分析中的缩小预览也不能当作全尺寸导出基准。
当前内置逐滤镜计时主要覆盖实际 FFmpeg 效果链；嵌套合成的缓存准备计入准备阶段。
