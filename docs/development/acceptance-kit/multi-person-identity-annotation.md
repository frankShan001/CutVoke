# 多人身份跟踪参考标注

## 拍摄素材要求

- 15–30 秒连续、未经剪辑或遮挡修补的视频，画面里至少两人；两人应各自移动并发生交叉，含部分或完全遮挡。
- 需有权在本机进行产品测试。不要上传或公开发布素材；不需要记录人物姓名、脸部身份或其他个人信息。
- 画面中选择两名可区分人物作为匿名目标 A、B。只记录稳定可见的服装/随身物颜色等视觉提示，例如“浅色外套”“红色背包”。

## 填写方法

1. 在 `multi-person-identity-annotations.csv` 中为 A、B 分别记录可见关键帧的归一化边界框。建议至少每秒一个标注点，并对交叉前、接触/遮挡期间和遮挡后加密标注。
2. `bbox_*_norm` 范围为 0–1，以左上角为 (0,0)、右下角为 (1,1)。完全遮挡时四个边界框字段留空，`occlusion_state=full`，并填写事件说明。
3. 记录交叉开始/结束以及每段遮挡的起止时码。不要在多人重叠时强行标出不可见的人体边界；如身份无法确认，写 `uncertain` 并说明原因。
4. 跑 CutVoke 跟踪后，独立评估者逐帧核对预测掩码对应的 A/B 目标。报告身份切换数、丢失区间、遮挡后恢复正确率和失败画面；不以“画面中仍有任意人物掩码”作为通过。

只有视频和参考标注均真实完成，并保存模型版本、提示点、逐帧结果与复核记录，才能将 JY-R20 的多人身份跟踪验收标为通过。
