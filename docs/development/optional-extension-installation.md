# 可选扩展的安装与下载设计

状态（2026-10-27）：Windows x64 的共享安装器已接通界面、HTTP 和 MCP；人物、SAM2 CPU、SAM2 CUDA 12.8 三种固定方案已在新下载的独立 Python 环境中完成安装和真实推理检查。安装包不附带模型或 PyTorch，用户无需准备 Python/Git。macOS/Linux 的一键安装包尚未验收，安装计划明确返回 unsupported；已有手动配置的运行环境仍可使用。

## 首次使用与确认

- 常规安装包不含神经抠像模型及其独立运行环境。首次启动直接进入剪辑首页，基本编辑、预览和导出不依赖扩展。
- 仅在用户使用相关功能时检查设备、磁盘和扩展状态。未安装是正常的可选状态，不显示为软件损坏。
- 安装前展示用途、预计下载量、安装后占用空间及设备适用性；下载量和磁盘占用分别计算，不能用权重大小代替整套环境大小。
- 同一安装请求只确认一次。用户已明确授权安装时复用该授权；换下载线路但制品、版本和资源范围不变时不重复询问。
- 界面与 MCP 共用安装计划、确认记录、安装任务和取消操作。已安装的扩展供同一用户的所有工程复用，不放进工程包，也不逐工程重复下载。
- 普通用户不需要安装 Git、输入 pip 命令或理解 CUDA。安装流程由 CutVoke 管理自己的独立环境，不改动用户的全局 Python 配置。

## 制品与下载来源

优先提供经过验收的预构建扩展包，按系统、架构和计算后端区分；模型权重独立缓存。安装时按已验收的兼容矩阵选择固定版本，不在用户电脑上临时解析并安装任意最新版依赖。

| 制品 | 海外来源方向 | 大陆来源方向 | 实现要求 |
| --- | --- | --- | --- |
| 独立 Python/运行环境包 | 官方发行源或项目受控分发 | 经授权的项目大陆分发 | 精确匹配系统和架构；用户无需自行安装 Python |
| 通用 Python wheel | 官方 PyPI 或固定制品集 | 经验证的 PyPI 镜像或项目受控分发 | 固定版本、文件哈希；只配置本次独立环境 |
| PyTorch/计算后端组件 | PyTorch 官方对应构建源 | 对应构建的可信镜像或项目受控分发 | 独立管理 CPU/CUDA 等构建；通用 PyPI 镜像不视为 CUDA 构建镜像 |
| SAM2 程序包 | 固定提交构建出的 wheel/扩展包 | 同一制品的受控副本 | 最终用户安装不依赖实时访问 GitHub 或本地源码编译 |
| 模型权重 | Google/Meta 官方固定版本文件 | 经授权并独立校验的同版本副本 | 所有候选源必须对应同一个已审核文件哈希 |

实际固定清单位于 `src/cutvoke/catalogs/optional_extensions.json`：Python 使用官方、NJU 和华为源；通用 wheel 使用 PyPI/NJU；CUDA 12.8 使用 PyTorch 专用源/NJU 对应构建；SAM2 权重使用 Meta/ModelScope；两个轻量模型使用 Google 和项目 GitCode 的固定 blob。GitCode 分支 `codex/optional-model-downloads-v1` 同时保留 Apache-2.0 授权和来源记录。第三方同名文件必须通过原始文件 SHA-256 校验。

SAM2 固定提交生成的纯 Python wheel、ANTLR/iopath 小型 wheel 和 CutVoke 工作进程代码随基础包分发，总计约 1 MiB；不要求用户实时访问 GitHub、安装编译器或编译 CUDA 扩展。构建时重新生成并校验工作进程代码包，源码安装脚本不再是普通用户的安装入口。

公开 PyPI 镜像只是依赖来源之一，不能替代模型文件、GitHub 程序包和 PyTorch 专用构建的下载方案。每个候选来源单独记录实际覆盖范围和验证状态。

## 自动选路与恢复

- 默认“自动选择”。基于本次网络实际连通性做有超时、有总预算的小流量探测，不能仅凭中文界面、系统区域或 IP 地区认定线路。
- 高级设置提供“自动选择 / 大陆线路优先 / 官方线路优先 / 导入离线包”。手动优先级仍受制品校验约束；不向普通用户展示一长串源地址。
- 使用发布清单中的可信候选来源；按可用性、稳定性和传输表现选择，不能只比较首页能否打开或一次 HEAD 请求的延迟。
- 遇到断连、超时、限流或制品不可用时，在有限重试预算内切换来源。保留已完成并校验的文件；同一下载的断点恢复需验证文件身份和 Range 响应，不能混接不同版本的内容。
- 每个文件校验预期大小和 SHA-256。发布清单本身要有可信发布链；通过校验后才进入安装阶段。切换来源不能改变预期版本、平台、后端或哈希。
- 支持取消、缓存复用和重启后继续。使用暂存目录和原子切换，失败不破坏已有可用版本。并发 GUI/MCP 请求合并到同一安装任务。
- 遵守用户代理设置，不要求用户修改系统网络或关闭证书校验。提供具备同样版本、平台和哈希校验的离线包入口。

## 普通用户看到的反馈

常规流程显示用途和整体进度，将具体模型、依赖和域名放到“更多信息/诊断”中。

首次启用示例：

> 启用物体抠像后，可以跟踪人物或物体并移除背景。首次需要下载附加组件，安装后约占用 X GB 空间。
>
> 安装并启用 / 暂不启用

下载遇到问题时：

> 当前线路较慢，正在尝试其他线路。

候选来源均失败时：

> 下载暂时无法完成，已下载内容会保留。可稍后重试或导入离线包。

网络故障、模型未安装、磁盘不足、设备不适合和 AI 不支持图片输入需要分别解释；不能一律显示“设备不支持”。提示不得暗示必须配置代理才能继续使用基本剪辑。

## MCP 与用户的 AI

以下交互已通过 `extension_status/plan/confirm/install/job/export_offline` 提供，不要求先创建工程或打开 GUI。

- 发现工具和查询状态不触发下载安装。状态提供功能用途、是否安装、设备适用性、安装计划、下载与占用估算、网络可用性、用户确认状态和可采取的下一步。
- AI 在首次使用视觉抠像前，自行判断当前模型和客户端是否支持读取实际工具图片。不支持或不确定时不走 AI 视觉选取/验收流程；人工界面仍可独立使用本地模型。
- 用户任务需要扩展但尚未授权安装时，返回 needs_user_confirmation、用途和资源估算，由正在与用户对话的 AI 询问。`extension_confirm` 记录真实回答并生成确认凭据，`extension_install` 必须携带对应凭据。当前没有实现客户端 elicitation 协商或通用宿主弹窗，不能宣称已支持。
- 用户明确同意后，由安装接口使用对应计划与确认记录执行；AI 查询任务状态并恢复原任务，不拼接安装命令替代安装器。
- 自动切源属于同一次安装任务，AI 不需要逐源向用户请示。只有安装范围、所需组件或资源代价发生实质变化时，才重新说明并按已有授权范围处理。
- 下载全部失败时，返回可重试的下载状态、诊断及离线包选项。AI 说明这项处理尚未完成，可以继续其他编辑；不能把失败替换成成功或当作设备能力结论。
- GUI 不要求保持打开；MCP 首次使用也能完成计划、确认、安装、进度和取消。打开 GUI 后看到同一安装状态，不重复弹窗或重复启动下载。

## 发布验收

本轮实测：大陆直连出口探测为 CN，系统代理出口探测为 SG。45 个外部制品在两条线路分别完成整文件传输和 SHA-256 校验；另外完整校验了 GitCode 两个模型的双线路下载及华为 Python 备用源。代理可能按域名分流，这不是独立海外实机，也不能代表大陆所有运营商。首次实际下载与后续缓存复核分别记录，缓存命中不当作新下载。

工程内 `.artifacts/extension-installation/` 保存来源校验、三套新环境安装/推理、浏览器流程及冻结引擎验收记录。设备检查不是性能承诺；合成短片验证不是复杂发丝、运动模糊或长遮挡的质量基准。安装前空间预算包含下载、临时 wheel 副本、解压后运行环境和安全余量。拒绝或失败保留普通剪辑能力；安装失败不替换已激活环境。

冻结后的 Windows 引擎已在 PATH 中没有 Python/Git、扩展目录与下载缓存为空的条件下，完成 MCP 初始化发现、无确认拒绝、确认后在线安装、HTTP/MCP 共享状态、安装请求幂等及离线包导出/导入。最终构建还通过了 semantic、MagicTouch 和 SAM2 三种完整私有工作进程作业，各生成并解码 8 帧；SAM2 验证覆盖冻结程序从内置 ZIP 提取工作脚本的路径。这里使用现有 Windows 主机，并非干净虚拟机。

后续来源验收可以显式运行 `tools/qa/verify_optional_extension_sources.py --region cn --direct --fresh` 和 `--region global --fresh`。此工具会下载多个 GB，请在对应真实网络中单独运行；报告明确区分首次网络传输、续传和缓存命中，不能将代理配置本身当作地理位置证明。

后续发布仍需按下面的场景在目标平台持续验收：

- 在干净设备上验证，无开发环境、无模型、无 Git 也能完成所选扩展安装。
- 分别验证海外网络和真实大陆网络下的完整下载、校验、安装和短片段推理；记录具体制品、系统、架构、后端和实际线路。不能用当前开发机已有缓存证明新用户可以安装。
- 模拟官方源不可达、镜像不可达、限流、中途断连、错误哈希、磁盘不足和用户取消，验证切源、恢复、诊断和已有版本保留。
- 模拟跨源续传身份不匹配，验证拒绝混接；对已完成文件不重复下载。
- 验证 CPU/CUDA 等方案不会因网络回退而悄悄更换；真实设备是否适合运行与网络状态分别判断。
- 验证 GUI 先安装、MCP 先安装及两者同时请求；同一次安装只需一次确认，后续使用不重复询问。
- 模拟域名阻断只能验证回退逻辑，不能替代真实大陆或海外网络的安装验收。未通过验收的来源不标记为已支持。
