日期：2026-10-22。交付范围：完整文字策划与录制清单。当前未录屏、未配音、未创建 CutVoke 工程、未导出视频、未保存或分享特效模块。

完整逐镜头中英文旁白见 [01-中英文旁白.md](01-中英文旁白.md)，镜头 ID 一一对应。下文是未来制作指令，不是已完成记录。

## 1. 已确定的创意与结构

- 受众：希望使用 AI 剪辑，同时能够自己接手调整的创作者；对开源创作工具感兴趣的用户和开发者。
- 定位：让人与 AI 共同创作的开源视频剪辑软件。
- 三个价值：① 改几个字，很简单。② AI 怎么剪的，你看得见，也改得了。③ 打造自己的特效库，也能互相分享。
- 顺序：痛点开场 → 完整摩托案例 → 真实工程 → 三个价值的操作证据 → 本片工程与行动入口。
- 目标：16:9，约 2 分 42 秒，1080p 交付，暂按 30 fps 主工程规划。摩托案例保留原速度与完整内容；原片时长、帧率在实际制作时核对，不能为卡时间裁掉内容。
- 英文主版建议：英文界面、英文旁白、英文短标题；中文旁白为独立版本。英文版中文字幕单独对齐制作。
- 时间基准：S08 暂按文档记载 22.333 秒计。所有小数秒均为内容排布标记，不是帧级 EDL。实际配音和素材确认后再换算帧边界。

| 段落 | 目标时间 | 目的 |
| --- | --- | --- |
| 痛点与两条改字路径 | 0–31 秒 | 让观众立即理解“为什么需要它” |
| 案例引入 | 31–36 秒 | 给完整观看建立预期 |
| 完整摩托成片 | 36–58.333 秒 | 以实际作品展示广告短片质感 |
| 成片进入工程 | 58.333–66.333 秒 | 把视觉结果与可编辑对象连接起来 |
| 改几个字 | 66.333–86.333 秒 | 交代操作证据，回扣开场 |
| 看得见、能接手 | 86.333–116.333 秒 | 工程、界面、历史、人工微调、AI 继续做 |
| 本地积累与分享 | 116.333–146.333 秒 | 保存、复用、分享、导入他人模块 |
| 自身工程与片尾 | 146.333–162.333 秒 | 产品自证与试用入口 |

### C. 特效模块演示

- 选一个实际 schema 支持的效果组合，优先短促的不透明度入场与可用的颜色/文字样式；先验证，再确定镜头。
- 演示模块 A：本次创建并保存，工作代号“Clean Reveal”（作为脚本标签，不预设系统有命名字段）。
- 第二段素材：与 A 不同的镜头，用于证明跨素材复用；如选文字样式，应在目标上保留不同正文，证明复用样式不会复制原文字内容。
- 模块 B：真正来自其他贡献者的可导入分享包。记录来源、作者、许可证、兼容版本。现有声明式转场 manifest 不一定等于可导入的 recipe ZIP，必须核对格式。
- 当前文档明确支持效果模块的保存、应用、导出和导入。若没有可用的 GUI 按钮，录制外部 AI 客户端执行实际模块工具，再回 CutVoke 查看结果；不设计不存在的按钮或社区市场页面。
- 模块 A 与 B 都要有应用前后画面。图标堆叠或“我的特效库”概念图不作为保存/导入成功的证据。

### D. 宣传片主工程

未来由 CutVoke 完成所有时间线编辑、图文合成、缩放强调、混音与 MP4 导出。录屏工具只采集画面。AI 客户端是外部工具，镜头中标清，避免让观众以为 CutVoke 内置聊天模型。

片尾 S25 的本片工程画面安排在主剪完成后补录；不需要让工程无限包含自己。录制主工程时间线，将短录屏插入片尾，再完成最终导出。

## 4. 可直接用于录制的 AI 请求

这些是未来录制时发给外部 AI 的自然语言，不是本轮执行授权。真实 project ID、对象 ID、revision 与模块参数由 AI 查询；不要让它修改原摩托工程。录制前按当前 editor_help 确认操作入口。

### P1：只修改指定文字（D1 → D2）

中文：
> 在当前演示工程中，把独立文字层里的“CHASE THE NIGHT”改成“FOLLOW THE NIGHT”。先定位原句和目标对象，只读取必要的信息；保留位置、颜色、字体、大小、时间和其他片段。修改后让我在 CutVoke 中查看，不要导出整支视频。

English:
> In the current demo project, change the editable text “CHASE THE NIGHT” to “FOLLOW THE NIGHT”. Locate the original text and read only what you need. Keep its position, color, font, size, timing, and every other clip unchanged. Let me review it in CutVoke; do not export the full video.

### P2：读取人工记录后继续改（D3 → D4）

中文：
> 我刚调整了标题的位置和颜色。请先读取最近的人工编辑记录及当前标题状态，再把“FOLLOW THE NIGHT”缩短为“NIGHT RIDE”。只改文字，保留我调整的位置、颜色和其他属性。修改后让我查看预览，不要导出。

English:
> I just changed the title's position and color. Read the recent human editing events and the current title state, then shorten “FOLLOW THE NIGHT” to “NIGHT RIDE”. Change only the wording. Keep my position, color, and all other properties. Let me review the preview; do not export.

### P3：积累本地效果模块

中文：
> 把这次已经验证的效果参数保存成可复用的本地效果模块。先确认模块格式支持哪些字段，只保存支持的效果、运动或文字样式，不保存文字正文或素材。保存后把同一个模块应用到另一段演示素材，让我查看前后效果。暂不导出分享包。

English:
> Save the effect settings we have verified as a reusable local effect module. Check the supported schema first. Save only supported effects, motion, or text styling—not the text itself or media. Then apply the same module to another demo clip so I can compare the result. Do not export a sharing package yet.

### P4：准备本地分享包

中文：
> 为刚才保存的效果模块准备一个只含效果配方的本地分享 ZIP，并完整显示实际工具要求的隐私说明。不要添加素材、文字正文、工程、截图或历史，也不要上传或公开提交。

English:
> Prepare a local, recipe-only sharing ZIP for the effect module we saved, and display the complete privacy notice required by the tool. Do not add media, text content, projects, screenshots, or editing history. Do not upload or publish anything.

当前贡献文档中的中文说明（录制时以工具返回原文为准）：

### P5：添加分享模块

中文：
> 导入这个已核对来源和许可证的效果模块分享包，列出导入后的模块，并应用到指定演示素材。保留目标素材与文字正文，让我在 CutVoke 查看效果，再调整一个支持的参数。不要把导入操作说成已经向社区发布。

Show the result in CutVoke, then adjust one supported parameter. Importing does not mean publishing anything to the community.

## 5. 拍摄顺序与原始素材清单

按依赖顺序录制，而非按成片顺序反复改工程：

| 批次 / 建议源文件名 | 对应镜头 | 录制内容 |
| --- | --- | --- |
| R01-editor-and-typo | S01–S03、S15 可用画面 | 演示工程 D0 的全貌、错字、选择对象 |
| R02-manual-text-fix | S05、S11 | 完整记录 D0→D1，保留操作前后余量 |
| R03-ai-text-fix | S06、S12–S14 | 外部 AI 发指令、实际调用、D1→D2、编辑器预览 |
| R04-history-and-handoff | S15–S19 | AI 修改历史、D2→D3 人工调整、AI 读取人工记录、D3→D4、结果 |
| R05-motorcycle-project | S07、S09–S10 | 打开摩托完整编辑副本，定位原片尾部、轨道与图层 |
| R06-local-effect-reuse | S20–S22 | 保存 A，另一个素材/工程应用 A，调整、重新查询 |
| R07-sharing-and-import | S23–S24 | 导出 A 的配方 ZIP、核对并导入 B、应用预览；保留来源资料 |
| R08-promo-project-late | S25 | 主剪完成后补录真实宣传片工程 |

建议录屏源为 2560×1440 或更高、16:9、30 fps，按实际机器表现选择，避免高分辨率导致交互掉帧。最终至少保证 1080p 下目标文字可读。统一界面语言与缩放，关闭无关通知，录屏不露账号、密钥、私人文件列表。原始过程完整保存，剪辑版只去除无关等待和重复动作。

每批附一小段文字记录：使用的构建/提交、工程 ID、开始结束 revision、真实耗时、是否压缩等待、模块 ID（如有）、成片镜头 ID。无需收集无关个人日志。

## 6. 剪辑、字幕与声音规则

- 全部编辑、合成、文字、混音与最终导出在 CutVoke 内完成。只使用实际可用的缩放、裁切、文字与转场；复杂动效不是完成宣传片的前提。
- 旁白逐句字幕与三条价值标题分开排版。字幕不遮目标文字、属性控件、历史记录或 AI 请求；必要时换字幕位置，避免缩小到不可读。
- 价值一用操作前后差异；价值二用完整工程、历史与接手；价值三用保存/复用/分享/导入。不要用同一段聊天画面重复证明三件事。
- 开场 S04 流程示意与真实录屏有明确视觉区别。概念卡片不贴软件边框，不伪装为实际功能。
- 摩托原片全屏完整播放，保留声音，不加讲解字幕。S07 结束前收掉开场音乐；S08 结束后才引入功能段音乐，不削掉原片尾音。
- 功能段音乐保持低声压，文字变化/切换可加克制反馈音，不用每次点击都配重音。最终听检旁白清晰、无突变和削波。
- 不宣称“所有操作永远都有完整历史”“绝不会冲突”“无需任何渲染”“任何文字都能直接改”“自动沉淀所有效果”“节省固定比例 tokens”。让真实演示承担证据。
- 关于 token：手工修改无需调用 AI；AI 可按需读取和局部修改。模型思考与上下文用量仍因任务而异，渲染不是 token 计量本身。
- 开源软件许可证不自动覆盖案例音乐或个人素材。制作前核对所用声音与分享模块范围；旁白无需加入长篇许可说明。
