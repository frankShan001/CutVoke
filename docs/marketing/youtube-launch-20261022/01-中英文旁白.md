日期：2026-10-22。状态：供审阅的文字脚本，未配音、未录屏、未创建视频工程。

结构：改字痛点 → 完整摩托案例 → 三个产品价值 → 试用与分享。

对应录制要求见 [02-逐镜头录制脚本.md](02-逐镜头录制脚本.md)。纯中文与纯英文配音稿分别见 [03-中文配音稿.txt](03-中文配音稿.txt)、[04-English-voiceover.txt](04-English-voiceover.txt)。

## 配音说明

- 中文、英文是两个独立版本，不在同一支视频中轮流朗读。英文采用自然口语改写；两版含义和镜头一致，不强行逐字对应。
- 建议 YouTube 主版采用英文旁白与英文界面；中文稿可用于审稿、另配中文版。中文字幕须从最终英文配音对齐翻译，不能直接按本表时间生成最终 SRT。
- 语气：像创作者介绍自己真正使用的工具。开头利落、有一点自问自答的幽默，功能段清晰平实，结尾邀请参与。
- CutVoke 的品牌读音录制前由项目方定音；英文 tokens 正常朗读，中文可读作“token”。不在片中解释接口、版本锁或数据库。
- 下列为粗剪目标时间。约 162.333 秒（2 分 42 秒）；摩托完整片长暂按项目说明的 22.333 秒排布，制作时以真实文件时长为准。旁白先试读，再调整录屏段时长，不压缩摩托成片、不强行加速配音。
- 摩托案例段无旁白；片尾最后 5 秒无旁白。各行的停顿、呼吸包含在镜头时长内，不逐行机械读停。
- 关于速度和 token 的表达为流程收益，不包含实测百分比或秒数。最终交付新 MP4 仍需导出；这里说的是检查修改时无需先导出整片。

## 使用条件

- S04 只描述需要反复生成和渲染的工作流，不声称所有视频工具都如此；渲染等待与模型 token 消耗分开表达。
- S09–S10 要打开摩托完整编辑工程，而非把最终 MP4 放进时间线的对比工程。
- S18–S19 需要实际完成“读取人工修改 → 保留位置和颜色 → 只改文案”，不能仅以 AI 的口头确认代替证据。
- S20–S24 使用实际支持的模块格式。单个模块与整套库要区分：可通过多个模块逐步积累、导入和分享，不虚构一个“一键发布整个库”按钮。
- S24 需真实的其他贡献者模块及来源记录。如果制作前仍未取得，改用“导入分享包”的功能演示，旁白相应改为：“你也可以导入分享的效果模块，继续使用和调整。” / “You can also import shared effect modules, then use and customize them.” 不把自己复制的模块冒充其他用户作品。
- S25 为未来交付后的文案。只有本宣传片确实由 CutVoke 完成剪辑、合成、混音和导出后才能使用，当前不表示视频已完成。
