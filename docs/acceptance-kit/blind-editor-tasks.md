# 独立剪辑者盲测任务

## 主持人准备

1. 邀请 3 位未参与 CutVoke 开发或验收设计的剪辑者。记录匿名代号 P01–P03、剪辑经验年限区间、常用软件和 CutVoke 使用经验；不记录姓名或联系方式。
2. 在同一台机器、同一浏览器版本上启动已构建的 CutVoke。每人使用相同的六段 Commons 素材包和一份全新解压的起始工程副本。将第七段 `afn-naples-crosswalk-safety.webm` 导入素材库但不放入时间线，并确认每位参与者看到同一初始状态。
3. 确认工程可打开、素材齐全、测试数据目录彼此隔离。不要提前演示功能。
4. 告知参与者可以随时停止。测试结束后只保留匿名逐任务表，不收集姓名或屏幕录制。
5. 开始每项任务时记录开始时间；在完成、明确放弃或主持人因故终止时记录结束时间。主持人不指路、不解释控件；如果参与者主动求助，只记录求助内容，不给答案。

## 给参与者的开场说明

“请像平常做短片一样编辑这个工程。我会给你一些目标，不会教你按钮在哪里。你可以按自己的习惯完成，也可以随时停止。每个任务结束后告诉我你认为已经完成；若遇到阻碍，可以直接说出来。”

## 任务卡（按顺序原样宣读）

1. **素材筛选**：从素材库中找出目前没有用在时间线里的视频，预览后把它加入主轨。
2. **主轨移动与关联对象**：把主轨第二段视频向后移动约一秒。让跟随这段画面的字幕或贴纸仍出现在对应画面上；如果软件提供关联或联动选项，请按你认为合适的方式处理。
3. **转场时长**：在主轨前两段之间添加一种转场，并把它的时长调整到约一秒。
4. **变速和调色**：将第二段设为慢动作（约 0.75×），并把画面调暖一些。
5. **字幕编辑**：添加一句字幕“周末城市漫步”，将它放在第二段中合适的位置，并修正任何显示或时间问题。
6. **贴纸或特效**：在第三段添加一个适合画面的贴纸或画面特效，调整它的时间范围，使它只覆盖该段的一部分。
7. **保存与交付**：保存工程、关闭后重新打开，确认刚才的改动仍在；然后导出一份 720p MP4。

主持人不提示具体面板、搜索词、控件、快捷键或下一步做法。若目标因工程状态无法执行，记录为“受阻”，不要替参与者操作修复。

## 记录规则

- 每项任务单独计时；完成标准为参与者自己表示完成，且主持人能在工程中观察到对应状态。
- `completed_without_help`：独立完成填 `yes`；求助后完成填 `no`；放弃/不能完成填 `blocked`。
- `misoperations` 记录撤销、误删、错误应用、找错面板等可观察事件数量；具体过程写入 `notes`。
- 任务 7 的 `export_pass` 仅在 MP4 实际生成、能播放且时长/画面合理时填 `yes`。
- 每项结束后让参与者给操作难度打 1–5 分（1 很难，5 很容易），不要引导其解释好坏。
- 完成后填一份参与者总结。发布报告只用匿名汇总，不截取可识别的个人信息。

## 通过解释

这轮研究用于发现任务可完成性、用时、误操作和求助点，不把少量参与者结果称作统计代表性结论。至少 3 人实际完成、原始匿名记录完整后，才可更新 JY-R01、R04–R07、R09–R16、R18–R19 的独立体验证据。
