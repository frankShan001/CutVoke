## 工程就绪检查与恢复

新增只读统一命令 `project.preflight`，可选 `range:{start,end}` 使用导出相同区间校验。返回 `changedEntities[0].report`，包括 `readyToRender`、`errors`、`warnings`、去重文件列表及片段/轨道/素材 ID。

- 检查当前序列、复合片段的素材和启用的自定义 LUT；文件缺失、为空或是目录时定位错误。
- 隐藏片段、静音音轨、区间外片段的缺失依赖给警告；选区内转场检查前一片段。
- 不读取视频内容、不调用 ffprobe。文件可用性检查不等同完整解码；复合片段按保守依赖检查。
- 修复 `asset.swap` 只传 `assetId` 时未查素材账本、可能写入空路径的问题。未知 ID 失败回滚，保留时长、布局、动画与撤销。
- 清理 `caption.update` 命令目录中的重复参数；缺失路径的工程摘要保持可读。
- 修复命令预演会运行导出/文件处理或取消任务的副作用：这些命令拒绝 dry-run，命令目录标明 `previewSupported`；编辑及纯预检继续可预演。

核心回归：`test_project_preflight.py` 与 `test_core_collaboration_contract.py` 合计 37 项、91 子测试通过。新增 14 项覆盖千片段去重、缺失恢复、隐藏/静音、选区/转场、LUT 旁路、复合片段、空文件、目录、素材 ID 替换与撤销、预演无外部副作用。

## 渲染、长工程与预览

长动画不再按每个采样状态复制完整视频流。使用固定数量视频流计算连续几何和透明度，采样表达式以平衡分支求值；短预设保留已有渲染路径。窗口只编译时间区间内素材和转场需要的邻居，并在靠近目标素材处建立局部时钟。

复杂密集长片使用 8 秒 FFV1/PCM 无损中间窗口，顺序渲染后统一编码；字幕使用原序列时间，音频淡入淡出在裁剪前计算。精确帧率的黑色前缀和 concat 修复分窗转场末一帧提前切入的问题。新画面编辑可取消同工程过期预览；名称、收藏和纯字幕编辑继续复用底片，相邻窗口预取保留。

分窗策略保守用于超过 24 个可见音视频叶片段、导出长度超过 8 秒的工程，会增加无损中间文件占用和最终编码成本。带时间历史效果或反向播放的单个连续长源，仍可能需要解码窗口之前的内容；晚窗口测试证明的是大量短片段工程，不是所有连续长源都能恒定耗时寻址。

以下为本机真实素材、指定工程的采样记录，不是任意素材规模的性能保证。内存以每 0.1 秒观察 FFmpeg 子进程的 private bytes 计，非瞬时绝对峰值。

## Web 实际流程与播放器

- 素材账本中的原始名称用于素材面板、时间线和属性；导入音频后，已打开的音频分析面板即时更新候选素材。
- 导出前显示检查状态。缺失素材会阻止导出，提供片段定位和重新关联入口；网络检查失败保留设置并可重试。选区外缺失素材只产生警告，并已实际导出选区验证。
- 导出对话框在低高度视口内滚动；编辑器模块加载失败提供重新打开入口，保存工程可恢复。
- 不需要播放时钟的面板不再逐帧刷新。200 个独立 PNG 素材与 200 个时间线片段的实际工程通过播放中搜索及键盘操作检查，素材列表 DOM 保持有界。该检查不代表 200 路视频同时解码。
- 复播和循环回跳时同步播放器内部时钟引用，修复末尾重播后播放头停在零、字幕消失的问题。缩小预览时按缩放比例设置字幕描边，白色填色保持可见。
- 字幕面板新增 Sans/Serif 字体选择；批量样式、清除样式、撤销/重做和保存重开共同保留字体选择。四组常规/粗体的实际 Web 图与成片均已直接目视对照，字形、尺寸、字重和时码一致；浏览器与 FFmpeg 光栅化不宣称逐像素相同。

字幕预览与导出统一读取随包 Sans/Serif 字体。只有普通字幕按 CSS 像素字号换算 ASS 字号，并把 CSS 描边总宽换算成 ASS 外侧半径；现有标题渲染语义保持。当前 FFmpeg 选择可变字体默认细体，导出阶段用 fontTools 生成对应 400/700 字重的静态实例并原子缓存，匹配浏览器字重。

修复字幕字体参数被忽略的问题：`caption.add/update/patch/bulkAdd/batchStyle` 均支持 `Noto Sans SC` / `Noto Serif SC`，命令目录说明及查询字段同步。四项合同测试覆盖保存重开、持久化撤销/重做、预演不提交、批量样式、查询与错误回滚，六种非法输入均保持工程和 revision 不变。

`delivery/caption-consistency/font-cache-timing.json`：本机四种字体/字重首次生成约 8.3–11.4 秒，缓存命中约 0.3–1.5 毫秒。首次带字幕导出会增加这一步准备时间；没有字幕的预览不生成这些实例。fontTools 属于必要安装依赖，安装包诊断及独立环境验证覆盖该依赖。

## 仍需独立证据的质量门槛

本轮本地工作持续落实。以下不能由增加测试数量代替：

- 中文 ASR 商用准确率需要人工校对语音真值，既有社区字幕不等同真值。
- 多人抠像身份稳定性需要独立运动、遮挡和交叉素材；复制同一人物不能证明质量。
- 替代剪映的操作体验需要真实剪辑者独立盲测；程序回归不等同人类验收。
- 正式发行的签名、分发渠道和公开发布需实际发行配置。
